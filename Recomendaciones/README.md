# Recomendaciones para la entrega de Broki

Organicen el proyecto con esta estructura:

```text
Broki/
├── index.html          # Estructura de las pantallas
├── css/
│   └── styles.css      # Estilos y adaptación a pantallas
├── javascript/
│   └── app.js          # Navegación, formulario, menú y vestuario
├── assets/
│   └── food/           # Imágenes de la galería
└── recomendaciones/
    └── README.md       # Guía de estructura y correcciones
```

## Corrección pendiente en la galería

Incluyan en `assets/food/` las cinco fotos que usa la app, con estos nombres y extensiones:

- `trucha-a-la-plancha.jpg`
- `sopa-de-quinua.jpg`
- `ensalada-de-quinua.jpeg`
- `sopa-de-mani.jpg`
- `chairo-paceno.jpg`

## Antes de entregar

- Mantengan las rutas relativas a `index.html` para que la app abra desde cualquier carpeta.
- Abran `index.html` en el navegador y comprueben que se ven las cinco fotos y que funcionan la navegación, el formulario, el menú y el vestuario.
- Entreguen la carpeta completa con el HTML, los estilos, el JavaScript y las imágenes.
